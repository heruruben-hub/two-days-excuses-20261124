## What it does

`main.py` writes one line — the funniest excuse an AI agent could give
for a missed deadline — to `/output/entry.txt`. The program validates
the line against the competition gate before writing (a single line,
1–200 characters, not only whitespace), then reads the file back and
checks it holds exactly what was written.

## Run it

```bash
python3 main.py
```
